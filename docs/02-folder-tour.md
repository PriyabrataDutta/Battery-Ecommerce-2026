# Folder tour

```
src/
├── api/             Backend layer — one file per domain. Pure async functions.
├── assets/          Static images imported into components.
├── components/
│   ├── ui/          shadcn primitives (button, input, dialog…). Don't edit lightly.
│   ├── layout/      Header, Footer, StoreLayout, FloatingCTAs.
│   ├── products/    ProductCard, ShopFilters, ActiveFilters, FitmentSearch.
│   ├── cart/        CartDrawer.
│   ├── auth/        Route guards (RequireStaff, RequirePhoneVerified, …).
│   ├── search/      SmartSearch overlay.
│   └── admin/       Admin-only widgets (StatusPicker, ImageUpload, …).
├── hooks/
│   ├── queries/     React Query hooks (useProducts, useMyOrders, …) +
│   │                the qk key factory in keys.ts.
│   ├── useAuth.ts   Subscribes to the auth session.
│   ├── useCart.ts   Zustand cart store (client-only state).
│   └── use-toast.ts Toast helper.
├── integrations/
│   └── supabase/    AUTO-GENERATED. Never edit client.ts or types.ts by hand.
├── lib/             Pure utilities (formatters, adminLog, cn, …).
├── pages/           Route entry points. Folders for big ones (checkout/, …).
├── stores/          Zustand stores (currently just the cart helpers).
├── types/           Shared TS types not tied to one api file.
└── App.tsx          Route table + providers.
```

## Conventions

- **camelCase** for files exporting functions/hooks (`useProducts.ts`).
- **PascalCase** for files exporting React components (`ProductCard.tsx`).
- **kebab-case** for folder names of feature pages (`product-detail/`).
- One default export per page; named exports for everything else.
- No barrel `index.ts` files except for page folders. Direct imports keep
  tree-shaking honest and "go to definition" snappy.

## What you should almost never touch

- `src/integrations/supabase/client.ts` — regenerated by Lovable.
- `src/integrations/supabase/types.ts` — regenerated from the DB schema.
- `src/components/ui/*` — shadcn primitives. Wrap them in your own
  components rather than editing them in place.
- `supabase/config.toml` project-level settings.
